# Frontend AI Engineering Capstone

> Building modern, accessible web applications with AI-assisted development workflows.

## Project Overview

This repository is the capstone project for the **Frontend AI Engineering** track. It documents the journey of learning AI-assisted frontend development — from environment setup through building production-ready features — using Claude as the AI coding assistant.

## Tech Stack

| Layer | Technology |
|-------|------------|
| Markup | HTML5 (semantic) |
| Styling | Vanilla CSS (custom properties, grid, flexbox) |
| Logic | Vanilla JavaScript (ES2022+) |
| Tooling | Node.js LTS, Git, npm |
| AI Assistant | Claude (Anthropic) |
| Version Control | Git + GitHub |

## Development Conventions

- **Commits**: Conventional Commits 1.0.0 format (feat:, fix:, docs:, chore:, etc.)
- **CSS**: BEM-inspired naming, CSS custom properties for theming
- **JS**: ESM modules, async/await, no framework dependencies
- **HTML**: Semantic elements, ARIA where needed, single h1 per page
